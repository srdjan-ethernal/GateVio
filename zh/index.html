四大解决方案

一个识别平台，覆盖关键车辆流。

GateVio 将现场 AI 决策与中央指挥软件结合，可先从试点开始，再扩展到多个站点、车道、停车区或城市管控区。

01

边境与海关

面向出入境点的集中式 ALPR，支持快速车辆查询和跨站点通行历史。

  • 每次通行记录车牌、图像、视频、时间和 GPS
  • 按车牌、部分车牌、时间段或车辆图片搜索
  • 通过 REST API 对接现有机构系统
02

活动与停车

为大型活动、场馆和分布式停车场提供无票车辆准入和停车收入控制。

  • 支持已付费、VIP、物流、员工和媒体车辆规则
  • 实时查看各站点占用和收入
  • 支持支付和移动停车流程
03

高速公路与交通管理

监测高速公路和关键路段，并对安全和通行事件自动告警。

  • 按车道和方向统计车辆
  • 分析速度、流量和拥堵形成
  • 检测逆行、停车和排队
04

城市车辆准入控制

通过摄像头管理住宅区、步行区和保护区车辆进入，无需物理道闸。

  • 居民和授权车辆名单
  • 未授权进入的时间和图像证据
  • 集中查看所有受保护区域

边缘加云架构

现场亚秒级决策。全网集中控制。

GateVio 使用 NVIDIA Jetson 边缘计算进行本地识别和决策，同时通过云端提供仪表盘、分析、同步和多站点管理。

NVIDIA Jetson 边缘 AI

图像处理直接在控制点运行于 NVIDIA Jetson AGX Orin 或 Jetson Orin NX 硬件，降低延迟和网络依赖。

离线运行

网络中断时站点继续本地运行，连接恢复后自动同步记录。

REST API 集成

将 GateVio 连接到边境数据库、城市系统、停车平台、支付、准入控制和运营看板。
